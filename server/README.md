# CURT Backend Assessment — Server

Please refer to the main repository documentation: **[`../README.md`](../README.md)**.

### Quick Commands

```bash
# 1. Install Dependencies
npm install

# 2. Database Sync & Seeding
npm run db:push
npm run db:seed

# 3. Start Development Server
npm run dev

# 4. Run Automated Test Suites
npm run test:auth
npm run test:projects
npm run test:tasks
npm run test:ratelimit
```
